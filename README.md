# 악보 변환기 (Score Converter)

악보 사진을 올리면 Gemini가 음표·코드·가사를 읽고, 화면에서 확인·수정한 뒤
**가사가 들어간 고화질 PDF**, **MIDI**, **MusicXML(MuseScore에서 열기)** 로 저장하는 웹 앱입니다.

```
[GitHub Pages: docs/]
   ① PDF/사진 → 오선 줄(단)마다 자동으로 잘라 확대
   ② 곡 정보(제목·조·박자·구간)      ──▶ [Apps Script] ──▶ Gemini
   ③ 줄마다 음표 읽기 (4줄씩 동시에)   ──▶ [Apps Script] ──▶ Gemini
   ④ 오선 위치 → 음이름 계산(조표 반영), 줄 합치기
        │
        │
        ├─ Verovio 로 악보 그리기 (브라우저 안에서)
        ├─ PDF: 인쇄 창 → "PDF로 저장" (벡터, 확대해도 선명)
        ├─ MIDI / MusicXML / JSON 다운로드
        └─ 드라이브 저장 ──▶ Apps Script ──▶ 구글 드라이브 "악보 변환" 폴더
```

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `docs/index.html`, `style.css`, `app.js` | 화면 (GitHub Pages 에 올림) |
| `docs/score-model.js` | 악보 JSON ↔ MusicXML 변환, 오선 위치→음이름, 조옮김, 줄 나누기, 들보, 마디 길이 점검 |
| `docs/staff-split.js` | PDF 페이지 그리기(pdf.js), 오선 줄 찾기, 줄별 확대 이미지 |
| `docs/sample-amazing-grace.json` | "샘플 보기" 버튼용 예시 (저작권 만료 곡) |
| `apps-script/Code.gs` | Gemini 호출, 드라이브 저장 |
| `apps-script/appsscript.json` | Apps Script 설정(권한, 시간대) |

## 설치 (처음 한 번, 약 15분)

### 1. Gemini API 키 만들기
1. https://aistudio.google.com 접속 → **Get API key** → **Create API key**
2. 키를 복사해 둡니다. (남에게 보이면 안 됩니다)

> 무료 티어로 시작할 수 있지만, 무료 티어에서는 보낸 이미지가 Google 제품 개선에 쓰일 수 있습니다.
> 저작권 있는 악보를 많이 다룬다면 결제(유료 티어)를 켜는 것을 고려하세요. 사용량만큼만 과금됩니다.

### 2. Apps Script 만들기
1. https://script.google.com → **새 프로젝트**, 이름: `악보 변환기`
2. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 를 통째로 붙여넣기
3. 왼쪽 ⚙ **프로젝트 설정** → **"appsscript.json" 매니페스트 파일 표시** 체크
   → 편집기에 생긴 `appsscript.json` 을 `apps-script/appsscript.json` 내용으로 바꾸기
4. 같은 **프로젝트 설정** 아래 **스크립트 속성** 에 추가

   | 속성 | 값 |
   |---|---|
   | `GEMINI_API_KEY` | 1번에서 만든 키 |
   | `APP_KEY` | 웹 페이지에서 입력할 접속 암호 (아무 문자열, 예: `youngnak-2026`) |
   | `GEMINI_MODEL` | (선택) 비워두면 `gemini-flash-latest` 사용. 더 정확한 모델을 시험하려면 AI Studio 모델 목록의 이름을 넣으세요 |
   | `GEMINI_THINKING` | (선택) `low` 또는 `high`. "60초 제한" 오류가 자주 나면 `low` |
   | `DRIVE_FOLDER_ID` | (선택) 비워두면 처음 저장할 때 내 드라이브에 `악보 변환` 폴더를 자동으로 만듦 |

5. 편집기 위쪽 함수 목록에서 **`setupCheck`** 선택 → **실행** → 권한 승인
   (“확인되지 않은 앱” 화면이 나오면 *고급 → 이동* 을 누르면 됩니다. 내가 만든 스크립트라 괜찮습니다)
6. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (URL은 그대로)

### 3. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `/docs` → Save** 후 1~2분 뒤
`https://hanyj123-cmd.github.io/score-converter/` 로 접속합니다.

> API 키는 Apps Script 에만 있고 웹 페이지 코드에는 없으므로, 저장소가 공개여도 키는 노출되지 않습니다.

### 4. 연결
웹 페이지 오른쪽 위 ⚙ → **웹 앱 URL** 과 **접속 암호(APP_KEY)** 입력 → **연결 확인**
→ “연결됨 · 모델: …” 이 나오면 끝. (이 기기 브라우저에만 저장됩니다. 다른 폰/PC에서는 한 번씩 입력)

## 사용법

1. **악보 올리기** – PDF 또는 사진 (여러 페이지면 순서대로, 최대 6쪽). 썸네일에 "8줄"처럼 찾은 오선 줄 수가 나옵니다.
   "줄 못 찾음"이면 그 쪽은 통째로 읽기 때문에 정확도가 떨어집니다(사진이 기울어졌을 때). 반듯하게 다시 찍으면 좋아집니다.
   조·박자를 알면 골라 주세요. 정확도가 올라갑니다.
2. **변환하기** – 줄 수에 따라 30초~1분 30초. 진행 상황(3/8줄)이 표시됩니다.
3. **확인하고 고치기**
   - 노란 상자: 마디 길이가 박자와 안 맞는 곳, Gemini가 자신 없다고 한 곳 (누르면 그 마디로 이동)
   - 음표를 누르면 아래에 수정 창: 음높이(반음/옥타브 ▲▼), 길이, 점, 셋잇단, 붙임줄, 코드, 절별 가사
   - 음표 추가·삭제, 마디 나누기/합치기, **되돌리기**
   - 키보드: ← → 이동, ↑ ↓ 반음, Delete 삭제, Esc 닫기, Ctrl+Z 되돌리기
   - **원본 보기** 로 사진과 나란히 비교
   - **조옮김**: 원하는 조로 음표와 코드를 함께 옮김
   - **줄 나누기**: 기본은 **원본과 같게**(원본이 한 줄에 4마디면 4마디). *자동* 또는 *한 줄에 2~6마디*로 바꿀 수 있고,
     음표를 눌러 **"이 마디부터 새 줄" / "앞 줄에 붙이기"** 로 한 곳씩 직접 조정할 수도 있습니다.
   - **이 줄 다시 읽기**: 한 줄이 많이 틀렸으면 그 줄만 Gemini 로 다시 읽습니다.
4. **저장하기**
   - **PDF 저장/인쇄** → 인쇄 창에서 대상 **“PDF로 저장”** (휴대폰은 공유 → PDF/인쇄)
     **한 장에 맞추기**(기본 켜짐)는 넘치면 악보를 조금씩 줄여 한 장에 넣습니다.
   - **MIDI**, **MusicXML**(MuseScore 에서 *파일 → 열기*), **악보 JSON**(나중에 *불러오기* 로 이어서 수정)
   - **드라이브에 저장**: MusicXML·MIDI·JSON·원본 이미지를 곡 폴더로 저장

## 지금 버전의 한계

- **단선 악보**(멜로디 한 줄 + 코드 + 가사, 찬양 리드시트) 전용입니다. 피아노 반주 악보는 대상이 아닙니다.
- Gemini 인식은 완벽하지 않습니다. 특히 리듬(점음표·셋잇단)과 가사-음표 짝이 틀리기 쉬우니 꼭 확인하세요.
- `.mscz` 는 직접 만들지 않습니다. MusicXML 을 MuseScore 에서 열고 *다른 이름으로 저장* 하면 `.mscz` 가 됩니다.
- 드라이브에는 PDF 가 자동 저장되지 않습니다(인쇄 창에서 저장). 다음 단계 후보입니다.
- 반복은 도돌이표(|: :|)와 1·2번 괄호까지 지원합니다. D.S./Coda 는 아직 없습니다.
- 한 음표 위 여러 코드("Esus4 E7")는 음길이를 나눠 차례로 표시합니다.

## 콘티 앱과 연결할 때

- 공통 데이터는 **악보 JSON** 하나입니다. 형식은 `docs/score-model.js` 맨 위 주석에 있습니다.
- 콘티 앱의 곡 데이터에 `scoreJson`(또는 드라이브 폴더 ID)만 저장해 두면, 언제든 다시 그리고 조옮김·PDF를 만들 수 있습니다.
- 페이지 안에서는 `window.ScoreConverter.load(json)` 으로 악보를 띄우고, `ScoreConverter.score` 로 현재 악보를 가져올 수 있습니다.
- 콘티 앱의 곡 상세 화면에 "악보 변환" 버튼 → 이 페이지를 열면서 곡 정보를 넘기는 방식이 가장 간단합니다.

2. **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포** (URL 은 그대로)
